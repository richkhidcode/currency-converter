# Currency Converter

A simple responsive currency converter built with HTML, CSS, JavaScript and Bootstrap 5.

## Features
- HTML form for amount and currency selection
- JavaScript Fetch API for exchange-rate data
- 24 currencies, including GHS
- Responsive Bootstrap 5 layout
- Basic accessibility features such as labels and status messages
- Error handling when the exchange-rate service or internet connection is unavailable

## Run the app
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Use Live Server, or open `index.html` directly in a browser.
4. Make sure the computer is connected to the internet because the app requests exchange-rate data from a public API.

## Exchange-rate service
The app uses the free Open Exchange Rates API endpoint provided by ExchangeRate-API's public service (`open.er-api.com`).
